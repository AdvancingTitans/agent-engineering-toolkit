# Evidence-Guided Planner benchmark

Run:

```bash
python3 eval/evidence-guided-planner/run_benchmark.py
```

The evaluator reads 20 frozen localization contracts from
`tests/fixtures/planning/localization-gold.json`. Each contract contains three
separately frozen prediction groups:

1. `source_only`;
2. `bundle`;
3. `planner_protocol` (Bundle + Atlas + `/aet-plan` protocol).

Scoring invokes no Host Planner and cannot rewrite Gold or predictions. Gold
was independently authored as fixture contracts and marked frozen; it was not
generated by the evaluated Planner implementation.

Required-path recall, recommendation precision, required-test recall, linkage
omission, ungrounded and protected recommendations, conflict/UNKNOWN
preservation, reference resolution, and explainability are primary. Frozen
Token and elapsed-time observations are auxiliary only.

The checked-in result is
[`results/v1.17.0.json`](results/v1.17.0.json).

## Real code-Agent localization case

The frozen benchmark above tests deterministic contracts. The separate real
case records one bounded Codex `gpt-5.6-sol` planning observation against this
repository's own cross-module Atlas compatibility task:

1. `source_only`: current source, with source roots and generated/vendor
   exclusions fixed by the harness;
2. `v1_16_evidence_only`: the same task plus Bundle and Atlas, without Planning
   Context or a Plan;
3. `v1_17_plan`: the validated Plan package consumed by the code Agent's
   planning stage.

The gold contract, raw structured observations, and checked-in result remain
separate:

- [`real-case/gold.json`](real-case/gold.json)
- [`real-case/observations.json`](real-case/observations.json)
- [`results/v1.17.0-real-codex.json`](results/v1.17.0-real-codex.json)

Recompute the metrics and require byte-equivalent semantic results:

```bash
uv run --no-editable python eval/evidence-guided-planner/run_real_case.py \
  --output /tmp/aet-planner-real.json >/dev/null
cmp /tmp/aet-planner-real.json \
  eval/evidence-guided-planner/results/v1.17.0-real-codex.json
```

The scorer reports each metric independently. It does not produce a holistic
trust score. Against source-only, v1.17 improved production decision precision
by 55.56 percentage points, evidence-reference coverage by 100 points,
cross-edit linkage coverage by 66.67 points, and `UNKNOWN` preservation by 100
points. Required production-path and test recall did not improve because the
source-only observation was already 100% on those metrics.

The first unconstrained source-only attempt traversed vendored/minified assets
and failed the task budget. It was classified as a harness failure and is not a
scored observation. The recorded rerun applies the same source-root and
generated/vendor exclusions to all comparable groups.

This is one real case with one repetition per group. It is evidence that this
particular planning handoff improved the named scope-localization dimensions,
not a general model-quality, reliability, or release-authority claim.
