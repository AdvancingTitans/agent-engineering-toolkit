# Support

- **Bug:** use the Bug report form with a minimal public fixture.
- **Question:** use GitHub Discussions after the maintainer enables it.
- **Use case:** use the Use case form with reproducible, sanitized evidence.
- **Integration:** use the Integration form and include host/version details.
- **Feature:** explain the real workflow and why current surfaces are
  insufficient.
- **Security or sensitive evidence:** follow [SECURITY.md](SECURITY.md);
  never post details publicly.

Support is best effort. Remove credentials, private paths, customer data, and
raw private transcripts. AET maintainers cannot diagnose claims that cannot be
reproduced or safely inspected.
