# MCP

`aet mcp serve` exposes an optional stdio convenience layer for bounded AET
operations, including Portable Evidence Bundle, Evidence Atlas, Planning,
Review Graph, and Behavioural Risk Diagnosis. It does not replace the
self-describing artifacts and does not grant broader authority.

The official MCP Registry entry is currently
`DEFERRED_WITH_REASON`:

- PyPI is behind the repository version;
- namespace ownership has not been proven in this local task;
- the exact repository package is newer than the public PyPI package;
- external publication requires explicit human authorization.

Do not add or publish `server.json` until all tool permissions are documented,
the current official schema validates, public PyPI matches the GitHub Release,
and the publisher namespace can be verified.
