# MCP

`aet mcp serve` exposes an optional stdio convenience layer for Portable
Evidence Bundle operations. It does not replace the self-describing Bundle and
does not grant broader authority.

The official MCP Registry entry is currently
`DEFERRED_WITH_REASON`:

- PyPI is behind the repository version;
- namespace ownership has not been proven in this local task;
- the exact v1.18 package and current publisher have not been validated
  together;
- external publication requires explicit human authorization.

Do not add or publish `server.json` until the exact package launches, all tool
permissions are documented, the current official schema validates, and the
publisher namespace can be verified.
