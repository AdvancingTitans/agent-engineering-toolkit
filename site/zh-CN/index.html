面向 AI 编程 Agent 的可携证工作流

Agent 测的是现在这份代码，还是更早的版本？

AET 将测试执行、变更文件、产物与 Agent 声明绑定为可移交证据，并在证据失效时明确报告。

运行演示查看源码

一条命令，一个真实状态变化

uvx --from agent-engineering-toolkit aet demo stale-proof
测试真实执行 — PASS
proof 与被测源码一致 — EXACT_MATCH
相关源码变化但未重测 — RELEVANT_FILES_CHANGED

PyPI 当前仍是 v1.11.1；该命令是 v1.18 目标接口，精确版本发布前不得用于对外推广。

让证据贯穿交付

stale proof

保留历史通过事实，但不再把它套用到已变化的相关代码。

scope drift

依据人工授权的 intent 审查变更，不把所有跨模块工作误判为越界。

跨 Agent 交接

另一个 Agent 或人类无需安装 AET，也能读取 portable JSON/JSONL 证据。

证据不是授权

AET 不是另一个编程 Agent，也不替代测试或 CI。缺失证据保持 UNKNOWN，Plan 保持 PROPOSED；AET 不会自动编辑、提交、推送、合并或发布。
