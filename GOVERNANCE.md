# Governance

AdvancingTitans maintainers steward AET's repository, compatibility contracts,
releases, and external distribution. Maintainers decide by documented
technical evidence, user impact, security, maintenance cost, and the
Evidence-First product boundary.

External contributors may propose Issues and pull requests. Merge, release,
package ownership, remote settings, marketplace agreements, and public
statements remain maintainer decisions.

Public 1.x contracts preserve deterministic local behavior, explicit
`UNKNOWN`, Evidence/Observation/Advice separation, and human adoption
authority. A breaking authority change requires explicit review and release
classification.

No Agent, script, test result, or popularity metric can unilaterally authorize
a merge or release.
